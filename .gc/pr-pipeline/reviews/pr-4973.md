## Blocking findings

### 1. Assigned-work exhaustion is disconnected from production reconciliation

**Severity:** P0 · **Confidence:** medium · **Source:** Codex

The PR removes the daemon's assigned-work defer tracker construction, reload,
and `withAssignedWorkDeferTracker(cr.adt)` wiring. A nil tracker disables the
consecutive-deferral limit, so a session repeatedly deferring idle timeout on
the same bead can run forever while `assigned_work_defer_limit` is ignored.
The existing tests manually inject the tracker and do not exercise the
`CityRuntime` production path.

**Required fix:** restore the tracker field, construction/reload wiring, and
reconcile option; add a runtime-level exhaustion test.

### 2. Warm-bind delivery ignores a failed idle gate

**Severity:** P0 · **Confidence:** high · **Source:** Codex

`cmd/gc/warm_bind_nudge.go` discards every `WaitForIdle` error and nudges
unconditionally. A timeout, cancellation, or provider error can therefore
inject the claim prompt into an agent mid-turn; a successful nudge also writes
the marker and disables the safe retry path.

**Required fix:** do not nudge after `WaitForIdle` fails, leave the marker
unset, and cover the failure path with a provider test double.

### 3. Backpressure can leave a permanently silent lifecycle-event gap

**Severity:** P0 · **Confidence:** high · **Source:** Codex

Herdr sets `pendingResync` when the output channel is full, but retries it only
after another event or an already-armed relist timer. If the overflowing event
is the last frame before the stream becomes quiet, draining the consumer wakes
nothing and the contractually required resync never arrives. The current test
masks the gap by sending another event after draining.

**Required fix:** schedule an independent wakeup whenever `pendingResync`
becomes true; test overflow followed by drain with no additional provider
frame.

### 4. The pump treats a reconnect goroutine as an established stream

**Severity:** P0 · **Confidence:** medium · **Source:** Codex

The session-event pump marks itself streaming as soon as
`SubscribeSessionEvents` returns, while Herdr only starts a reconnect goroutine
at that point. Patrol stretching is therefore active before the first
connection, throughout outages, and even when the server never appears,
delaying corpse cleanup by the configured patrol interval.

**Required fix:** base stretching on actual connection health—enable it after
the first resync and disable it on transport loss.

### 5. Unattributed lifecycle events are discarded contrary to their contract

**Severity:** P0 · **Confidence:** medium · **Source:** Codex

The runtime contract says an unattributed lifecycle event must trigger broad
reconciliation, but the pump ignores it. A pane can exit before dynamic agent
mapping refreshes; on a stable connection no later resync is guaranteed, so
the death remains invisible until the potentially stretched patrol.

**Required fix:** issue a delayed, coalesced broad poke for unattributed deaths
without reintroducing the start-wave race.

### 6. Retiring nudge pollers silently strands delivery without a live controller

**Severity:** P0 · **Confidence:** medium · **Source:** Claude

The provider-shaped poller-retirement check suppresses sidecar pollers across
the nudge, sling, prime, wait, and submit paths, but the replacement event
dispatcher exists only inside a running controller. With the controller
stopped or crashed, commands can enqueue nudges successfully and leave them
undelivered without warning.

**Required fix:** include controller liveness in the suppression decision or
surface an explicit delivery warning/error on affected CLI paths.

### 7. Strict workdir validation turns a degraded start into a fleet-wide stall

**Severity:** P0 · **Confidence:** high · **Source:** Claude

`runtime.StageSessionWorkDir` does not create an absent configured workdir;
only a suitable `pre_start` command does. Herdr now rejects a set-but-absent
workdir after staging, so configurations without a worktree-creating
`pre_start` that previously fell back to `cityRoot` now fail every start with
no transition path.

**Required fix:** condition strict validation on a configured materializing
`pre_start`, or retain the `cityRoot` fallback with an explicit migration
warning.

## Additional findings

- **P1 / release safety (Claude + Codex):** the resource census banks total
  fixed sleeps from 431 to 468 and untagged sleeps from 286 to 323 across 114
  to 121 files, contradicting the ratchet's stated no-growth rule. Replace the
  new dispatcher, pump, and activity test sleeps with transition-driven waits
  before moving the baseline.
- **P1 / blast radius (Claude):** removing
  `primeHookHasLiveManagedSession` replaces five liveness/identity checks with
  `GC_SESSION_ID != ""`; closed or re-minted sessions can now enter the full
  prime path. Restore the independent guard cases and add closed-bead and
  session-name-mismatch tests.
- **P1 / resource lifecycle (Codex):** provider reload leaves each replaced
  Herdr activity tracker and self-healing subscription rooted in
  `context.Background()`. Give them an owned lifecycle and stop them on swap.
- **P2 / capability contract (Codex):** Herdr advertises `CanStream` for
  session events even though that field denotes the independent persistent
  `proc.stream` operation. Keep it false and use `SessionEventProvider` as the
  capability boundary.
- **P2 / signature safety (Claude):** the variadic warm-claim probe weakens a
  load-bearing signature and silently permits future callers to omit it. Make
  the parameter positional.
- **P2 / empty-queue work (Claude):** every patrol tick schedules a nudge pass
  and loads a session-bead snapshot even when the queue is empty. Short-circuit
  before the snapshot read.
